# v1.2.0-tandem.2 validation

`v1.2.0-tandem.2` was measured on the repository test suite and a clean macOS ARM64 installation: 196 Go tests/subtests passed with the race detector, reachable vulnerabilities stayed at 0, two six-platform Go 1.26.5 builds produced identical SHA-256 values, and one live PNG upload completed through the installed release. The release tag points to commit `292853d6c118394b18b2561dd10f2c7763dfde42`.

Clean pinned installation:

```console
$ gh extension remove image
$ gh extension install tandemhealth/gh-image --pin v1.2.0-tandem.2
$ gh extension list
gh image  tandemhealth/gh-image  v1.2.0-tandem.2
$ gh image --version
gh-image v1.2.0-tandem.2
```

Live upload of a synthetic 960×540 PNG from a dedicated evidence directory:

```console
$ GH_IMAGE_EVIDENCE_ROOT=/private/tmp/gh-image-v2-evidence \
    gh image /private/tmp/gh-image-v2-evidence/validation.png \
    --repo tandemhealth/gh-image
```
